### Create a new blob
POST http://localhost:3000/api/jsonBlob
Content-Type: application/json

[
  {
    "name": "Shadow",
    "type": "Dog",
    "age": 3,
    "gender": "Male"
  }
]

###


GET http://localhost:3000/api/jsonBlob/{{blobId}}

###


PUT http://localhost:3000/api/jsonBlob/{{blobId}}
Content-Type: application/json

[
  {
    "name": "Shadow",
    "type": "Dog",
    "age": 4,
    "gender": "Male"
  }
]

###


DELETE http://localhost:3000/api/jsonBlob/{{blobId}}
